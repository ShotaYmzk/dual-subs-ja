## A. 公開前に必ず確認すること（法務・権利）

- [ ] **A-1 PLaMo ライセンス（最重要）**
  - [ ] 公式の利用規約を自分の目で読む: https://plamo.preferredai.jp/info/plamo-community-license-ja
  - [ ] 拡張機能を公開して配る行為は、規約の「商用目的」（第1条9項: 製品・サービスの開発・提供を含む）に当たる可能性が高い。**無料でも、PFN の登録フォームで事前登録する**: https://forms.gle/mTL8tBLrMYXKNZD56 （第3条3項。条件: 事前登録＋あなた／関係会社の年間売上が10億円以下）
  - [ ] 「Built with PLaMo」を、ストアの説明・拡張の画面（案内・設定・ポップアップ・字幕一覧）に表示（実装済み。第4条1項）
  - [ ] 規約の写しを同梱（実装済み: `licenses/PLaMo-Community-License-*.txt`）。**同梱した写しは第三者の公開リポジトリ（2026-11-05 時点）から取ったものなので、公式ページの最新版と一致するか確認する**（私は公式ページが JavaScript 表示のため本文を直接読めませんでした）
  - [ ] 非公式であること、PFN の公式見解と誤認させないこと（第6条5項）を、説明文に明記（実装済み）
  - [ ] 18歳未満の利用は保護者の同意が必要（第2条）。規約を読んだうえで、必要なら説明に追記
- [ ] **A-2 名前と商標**
  - [ ] 「Prime」は Amazon の商標（Prime Video）。拡張の名前の先頭に使うと、ストアの審査や Amazon からの削除依頼のリスクが上がる。**名前から「Prime」を外す（対応済み: 「Dual Subs JA (PLaMo)」に変更）**（説明文の中で「Prime Video 向け」と書くのは問題になりにくい）。変更箇所は `_locales/*/messages.json` の `appName` と、各画面の「Dual Subs JA」の文字
  - [ ] 「(PLaMo)」は、PFN 公式と誤認されない書き方か確認（説明に非公式と明記済み）
  - [ ] Amazon / Prime Video のロゴや、実際の作品の画面写真は使わない（ストア画像はすべて自作の画像）
- [ ] **A-3 Amazon の利用規約**
  - [ ] 本拡張は、プレイヤーが自分で読み込む字幕を翻訳して表示するだけで、DRM の回避や動画の取得はしない。ただし Amazon の規約が自動化ツールを制限している可能性があるので、自分でも規約を確認する
  - [ ] Amazon から申し立てがあれば、ストアから削除される可能性がある（その前提で公開する）
- [ ] **A-3b Netflix / YouTube の規約と商標**
  - [ ] Netflix: 再生情報を読み取り、再生情報の要求を一部変更します（WebVTT と全字幕トラックを要求）。DRM は回避しませんが、規約が自動化を制限している可能性があり、Netflix からストアへ削除の申し立てが出る可能性は Prime Video より高いです。リスクを理解したうえで公開してください
  - [ ] YouTube: 字幕は、プレイヤーの字幕設定を自動でオンにして取得します（設定でオフにできます）。YouTube の規約・開発者向けポリシーを確認してください
  - [ ] ホスト権限が増えるため（netflix.com / youtube.com 全体）、ストアの審査が長引くことがあります。また「このサイトのデータの読み取りと変更」という警告が出ます
- [ ] **A-4 画像の権利**
  - [ ] プレビュー・ストア画像に使っている「雨の夜の街」の画像は、画像生成AIで作ったもの。その生成サービスの利用規約が、公開・商用利用を許しているか確認する（不安なら自分で撮った写真やイラストに差し替える）
- [ ] **A-5 同梱ソフトのライセンス**: すべて同梱済み（`NOTICE.txt`、`licenses/`）。WebAssembly の作り方は jammaru/sakutto（MIT）の手順とパッチを使っているので、その表記も入れてある
- [x] **A-6 プライバシーポリシー**: GitHub Pages で公開済み → **https://shotaymzk.github.io/dual-subs-ja/privacy.html**（連絡先は GitHub の Issues）。ダッシュボードの「プライバシーポリシーの URL」にこれを入れる

## C. 自動チェックの結果（私が実施済み）
- マニフェストの検証: 参照するファイルがすべて存在、アイコン 16/32/48/128、`default_locale`、権限は `storage` / `offscreen` / `declarativeNetRequest` のみ（不要だった `unlimitedStorage` は削除）
- 実行コードの外部読み込み・`eval`・`new Function` なし（同梱コードのみ）
- 作成した zip を新しいプロファイルに展開し、モデル取得（SHA-256 検証）→ WebGPU / CPU の翻訳まで動作確認

3. [ ] **ストアの掲載情報**

   - [ ] 小さいプロモーション画像 440×280: `store/images/promo-small-440x280.png`
